# KEROTOWN issue tracker

Found a bug in KEROTOWN, the Kero Learns Japanese game? Have an idea to make it better? Tell us here.

**[Report a bug or share an idea](../../issues/new/choose)**

Game ideas also show on **[Kero's ideas page](https://kerolearnsjapanese.com/ideas/)**, where anyone can tap a heart to back one.

Got an idea for a Kero **video** instead, like a word for Kero to learn? Share it in **[video ideas](https://github.com/Kero-Learns-Japanese/video-ideas)**.

You need a GitHub account to post here. GitHub accounts are for people aged 13 and over, so if you are younger, ask a grown-up to post for you.

## Keep yourself safe

Everything you post here can be seen by anyone on the internet.

- Never post your real name, your age, your school, where you live, your phone number or your email address.
- Never post a password, the code from a sign in email, or the code that opens the test version of the game.
- Before you add a screenshot, check it does not show any of these, or someone else's real name.
- It is fine to post the name you use in the game.

Posts that break these rules, or that are unkind, are taken down.

## What makes a good report

- What you were doing, and what went wrong.
- What you expected to happen instead.
- Where you were playing: in a web browser, on an Android phone, on an iPhone or iPad, or on a computer.
- A screenshot, if you can take one safely.

One problem or one idea a post is best, so each one can be fixed on its own.

## Find reports and ideas

Every post has a label for what it is and for the part of the game. Ideas also have one for where they are up to:

| Label | Means |
|---|---|
| `bug` | Something in the game went wrong |
| `idea` | Something new or better |
| `to do` | The idea is on Kero's list |
| `being made` | It is being made now |
| `maybe later` | Not for now |
| `done` | It is in the game (the issue is closed) |
| `fixed in the game` | A bug that is fixed now |

Click a label to see only those posts, or use these:

- [Bugs](../../issues?q=is%3Aopen+label%3Abug)
- [Ideas on the list](../../issues?q=is%3Aopen+label%3Aidea+label%3A%22to+do%22)
- [Ideas being made](../../issues?q=is%3Aopen+label%3A%22being+made%22)
- [Done](../../issues?q=is%3Aclosed+label%3Adone)

Give a post a 👍 if it matters to you too.

## What happens next

We read every post. A report we can fix gets a label and stays open until the fix is in the game. An idea that goes on Kero's list gets `to do` and shows on the ideas page from then on. If we need more from you, we ask in a comment.
